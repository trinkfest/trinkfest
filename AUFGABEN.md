# TrinkFest – offene Aufgaben (Stand 19.11.2026)

Jeder Block = **eine Sitzung**. Blöcke **nacheinander** abarbeiten (alle ändern `index.html`), nach jedem Block committen + pushen.
Start einer Sitzung: „Mach Block N aus AUFGABEN.md“. Erledigtes hier abhaken.

**Gilt überall:** Änderungen für Party- *und* Normal-Modus (Party = Schlücke, Normal = Strafpunkte). Im Normal-Modus, wo es Sinn macht, am Ende ein **Ranking mit Siegerpodest**.

## Block 3 – Schätz-Spiele + Emoji raten
**Schätzfragen**
- [x] Beim Eingeben der Antwort muss oben das Feld (mind. die Zeitleiste) sichtbar bleiben
- [x] Nächster dran: 0 Schlücke · Zweiter: 1 · Dritter und Rest: 2
- [x] Krass falsche Antwort (z. B. „Wie viele Menschen gibt es?“ → 100.000): groß anzeigen, 3 Schlücke – nur bei extremen Abweichungen

**Sekundenschätzen (Duell)**
- [x] Alle stoppen nacheinander; jeder bekommt eine eigene, aber nah beieinander liegende Zielzeit (z. B. 10/11/12 s) – fair, aber nicht gleich
- [x] Schlücke erst am Ende verteilen: große Liste 1./2./3. … – Erster 0, Zweiter 1, Dritter und Rest 2; Buttons „Nochmal“ + „Exit“
- [x] Auf Start/Stopp-Button steht nichts (keine Zahl, kein Wort)

**Sekundenschätzen (eigenes Spiel)**
- [x] Alles mittig zwischen Überschrift und unterem Handyrand
- [x] Ein Handy: wie im Duell (ähnliche Zeiten, wer am nächsten dran ist), Design anpassen
- [x] Online: Raum erstellen/beitreten, alle bekommen dieselbe Zeit, Auflösung am Ende, gleiche Regeln/Strafen wie im Duell

**Emoji raten**
- [x] Auch auf die Trinkspiel-Seite; wer richtig liegt, darf 2 Schlücke verteilen
- [x] Auflösung: Antwort **groß und fett**, sonst nur, wer richtig lag (und wie viele Schlücke er verteilen darf)
- [x] Ein-Handy-Modus: Emojis und Namen weiter nach unten (unten zu viel Platz); Popup „Chrisi war zuerst …“ auf Lösung + Gewinner + Schlücke kürzen

## Block 5 – Duelle Teil 2 (Brett-, Wissens-, Trinkduelle)
- [x] **Drei gewinnt:** klar als „Drei gewinnt“ erkennbar; Spieler blau vs. rot (Steine in der Farbe); Drop-Leiste weg, direkt in die Spalte tippen, Taler fällt; Boden klarer (Ständer größer o. ä.); Zurück-Button links oben, kein Dreh-Button
- [x] **Flaggen erraten:** Lösung darf nicht auf dem Button stehen, alles sauber anordnen
- [x] **Tic Tac Toe:** bei Unentschieden bis zu 3 Runden, dann Münzwurf
- [x] **Armdrücken:** ohne Countdown ins Spiel; beide drücken „Bereit“, dann großer animierter Countdown 3-2-1-GO; Gewinner erst nach 1 s antippbar
- [ ] **Wo liegt das:** Nord-/Südpol-Namen weg; kleinere, klarere Markierung aufs richtige Land; **kein Land/Gebäude doppelt in einem Spiel**; statt „Gib das Handy …“ → „[Name], du bist dran“ + Button „Ready“
- [ ] **Trinkduell:** Bereit-Screen neu (kein plumpes Bier-Icon, schöne Schrift, animierte Biere im Hintergrund); nach der Runde groß und klar, wer trinkt und wer nicht (Namen in Spielerfarbe); klarer, dass man auf ein Pferd setzt; Gewonnen/Verloren-Animation per Tippen überspringbar (ohne Hinweistext)

## Block 6 – Kartenspiele: Old Nick, Busfahren, Ass ziehen
**Old Nick**
- [ ] Bei falsch: „getrunken/weiter“-Text weg, nur „Diego trinkt 4 Schlücke“ + kurze Erklärung (4 zusammenhängende Karten) lassen
- [ ] „Abgeben“ nach 3 richtigen größer
- [ ] Tippbare Karten farbig leuchten lassen
- [ ] Dreh-Symbol rechts oben

**Busfahren**
- [ ] Jeder tippt „gemerkt/weiter“, erst dann kann der Host starten
- [ ] Falsch-Liste in Rot unter den Karten komplett weg
- [ ] Verlauf für alle sichtbar
- [ ] Wer busfahren muss, spielt es auf **seinem** Handy, nicht auf dem Haupthandy
- [ ] Endstatistik: farbiger Hintergrund mit Animationen statt weiß

**Ass ziehen**
- [ ] Wer dran ist: Name groß und auffällig
- [ ] Ablagestapel: immer oberste Karte offen, gleich groß wie Ziehstapel; auch Asse dort ablegen
- [ ] „Timon zieht Pik 5 – nichts passiert“ komplett weg; gezogene Asse größer
- [ ] „Alle Asse gezogen“ nicht weiß, sondern im normalen Spiel-Design

- [ ] Ganzes Spiel im klassischen Pferderennen-Look: Dirt-Bahn, Pferde mit Kartensymbol laufen vor, wenn ihr Symbol gezogen wird; „Pferderennen“ oben bleibt, Anweisungen oben integrieren – schon ab Spielstart

- [ ] Ziehstapel größer, „Tippe auf den Stapel“ weg, kein Cooldown beim Aufdecken

## Welches Modell für welchen Block
Modell beim Start der Sitzung in der App wählen.

| Block | Modell | Warum |
|---|---|---|
| 1 Allgemein + Bausteine | **Opus** | betrifft alle Spiele, baut Münzwurf/Podest für später |
| 2 Werbung & Kauf | Sonnet | wenige, klare Änderungen (config, iap) |
| 3 Schätz-Spiele + Emoji | **Opus** | neue Spiellogik + Online-Raum (Supabase) |
| 4 Duelle Teil 1 | Sonnet | viele kleine, klare Änderungen |
| 5 Duelle Teil 2 | Sonnet | klare Änderungen; bei Problemen auf Opus wechseln |
| 6 Kartenspiele | Sonnet | klare Änderungen (Busfahren online: bei Problemen Opus) |
| 7 Pferderennen | **Opus** | komplettes Neu-Design |
| 8 Party-Spiele | Sonnet | klare Änderungen |

Faustregel: neues Design oder Online/Mehrspieler → Opus; Texte, Größen, Regeln anpassen → Sonnet.

**Tokens sparen:** Große Blöcke in zwei Sitzungen teilen (z. B. „Block 5a: Punkte 1–4“, „Block 5b: Rest“). Unklare Punkte vorher hier entscheiden und dazuschreiben, woran man merkt, dass es fertig ist.
